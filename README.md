# 🚀 Matt's English Adventure

App web para repasar inglés de forma divertida antes del examen final.
Temas: Hobbies, Likes & Dislikes, Descriptions, My Friends, My Town, My Routine y Final Exam.

**Juegos por tema:** 🃏 tarjetas · 🔗 unir parejas · 🎧 escuchar · ⌨️ escribir · 🧩 armar frases · ✅ quiz
y especiales (🗺️ mapa del pueblo, 🕵️ Who is it?, 🕖 o'clock).

- Hecha con React + Vite + TypeScript + Tailwind.
- Sin login ni servidor: el progreso (estrellas) se guarda en el navegador.
- La pronunciación usa la voz del navegador (funciona mejor en Chrome/Safari).

```bash
npm install
npm run dev
```
